## Reproduction

Use a new disposable PostgreSQL database, `TEST_DATABASE_URL` and `ALLOW_TEST_DATABASE_RESET=yes`, then run `pnpm db:verify`. Run `pnpm test` against that initialized database, `pnpm db:types:check`, `pnpm db:seed:check`, `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm security:client`, `pnpm format:check` and `pnpm test:e2e --workers=2`. `E2E_PORT_OFFSET=10` uses ports 3010–3012 when the usual development ports are occupied. Do not run separate Playwright suites concurrently against the same output directory.

PDF fixtures and machine-readable timings are generated at `test-results/phase9-pdf`; this run's copies and rendered pages are retained under `output/pdf/phase9`. Browser evidence includes `test-results/brochure-editor.png` and `test-results/brochure-mobile-viewer.png`. Local execution logs are in `.tools/phase9-final-*.log` and are not deployment artifacts.

## Performance and acceptance boundaries

The full concurrent browser run generated the 10-page image-based profile in 7.38 seconds (3,090,626 bytes) and the 50-page text fixture in 12.44 seconds (79,719 bytes). Other two-page fixtures took 2.68–13.59 seconds. These are single local measurements under simultaneous test load, not production latency guarantees. An earlier isolated run took 2.81 seconds and 0.92 seconds respectively. Storage/list/version queries are bounded and indexed, but production multi-tenant load and large-library throughput have not been benchmarked.

Numeric resizing is implemented; corner resize handles and multi-selection group transformations are not. Rich text uses safe structured text and component typography rather than arbitrary HTML/inline markup. Custom fonts, PDF/X/CMYK certification, automatic text flow across pages and an external object-store adapter are not implemented. Templates contain honest editable placeholders and reused concept photography; they require approved business content before real publication. Direct private material/procurement imports are intentionally absent; approved catalog/manual material presentations are supported.

Hosted owner/designer/denied-role flows, QR scanning against a real public origin, hosted CRM enquiry verification and deployed revocation checks still require the configured development environment. The opt-in browser scenario has been authored but is not reported as executed. These boundaries prevent a claim of production readiness or exhaustive completion of every advanced editing requirement.
