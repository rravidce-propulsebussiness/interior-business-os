# Management reports

Reports are available at `/dashboard/reports`; the period-based management overview is `/dashboard/reports/overview`. Reports read canonical domain records and calculations, not copied reporting entities. Data pages contain at most 25 rows. Export snapshots capture up to 5,000 matching rows; users must narrow larger result sets. Project/customer pickers support text search and return at most 100 authorized matches. CRM includes a pipeline visualization; other dimension summaries use tables. Customer detail links to a combined, permission-filtered activity timeline.

| Family           | Source and calculation basis                                                                                                                                                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CRM              | Leads, follow-ups and activities. Stage, source, industry and location breakdowns use current canonical classifications.                                                                                                                                                         |
| Sales            | Quotation revisions and recorded customer responses. Current-revision accepted/rejected/pending/expired breakdowns are separate from revision history. Pending quote value is not revenue.                                                                                       |
| Billing          | Issued invoice total, confirmed payments and contract values are grouped separately by kind, status and currency. They are not added together.                                                                                                                                   |
| Receivables      | Issued invoice total minus current canonical payment allocations, floored at zero. Includes invoices created by the end date, regardless of start date. Aging uses the selected end date and increasing configurable boundaries. This is not a historical ledger reconstruction. |
| Projects         | Canonical projects and execution plans, filtered by current caller access.                                                                                                                                                                                                       |
| Procurement      | Requisitions, RFQs, vendor quotes, POs and receipts. Vendor/PO amounts additionally require cost-report permission.                                                                                                                                                              |
| Inventory        | Existing `operations_materials` ledger report: estimated/planned, ordered, received/accepted/rejected, issued, consumed, returned, scrapped, damaged, site/store balance, shortage and variance in explicit purchase units.                                                      |
| Cost             | Existing operations and commercial execution cost services. Contract, estimated, committed, received, consumed and certified amounts retain their distinct meanings.                                                                                                             |
| Execution        | Tasks, milestones, inspections, snags and handover records. Overdue work excludes completed/cancelled/resolved records.                                                                                                                                                          |
| Snags / handover | Existing issue and closure records. No invented resolution averages or subjective project-health scores.                                                                                                                                                                         |
| Subcontractors   | Canonical work-order and measurement status/quantity records. Detailed monetary cost totals remain in the permission-gated project cost report.                                                                                                                                  |

Ordinary report periods filter record creation in the organization timezone and show current status/value. Inventory/cost reports are cumulative per project; the displayed date range does not truncate those balances. Overview work counts are current across all dates and are explicitly separated from period-based report sections. Financial sums remain numeric in PostgreSQL and decimal strings in responses. No browser-side money aggregation is used.

Filters cover date, project, customer, assignee, industry, location and status where represented by the source. Cumulative inventory/cost reports require a project and reject unrelated filters. Dimension breakdowns are limited to 100 groups. Unknown configuration, invalid IDs, reversed dates and ranges exceeding ten years fail validation.

Exports require `report.export`, the granular family permission and current source access. Immutable snapshots store filters, source basis, rows/aggregates, generation identity/time and renderer version. Every subsequent download rechecks current authorization, including project assignment and sensitive cost permissions. CSV cells neutralize spreadsheet formulas. PDFs use the existing bounded offline Chromium renderer with escaped HTML, repeating table headers and page numbers. No separate PDF engine or public export route is introduced. Snapshots preserve data, not byte-identical browser-generated PDF metadata.
