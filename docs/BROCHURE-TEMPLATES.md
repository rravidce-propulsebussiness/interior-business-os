# Editable brochure templates

Seven structured templates ship with the builder: Luxury Interior Studio, Modern Minimal, Residential Portfolio, Premium Modular Kitchen, Construction Company Profile, Architecture Portfolio and Corporate Profile. All are ordinary editable pages/components using the shared fixed-layout schema; there are no locked screenshots or executable template code.

The ten-page Interior starter includes cover, about, services, process, residential projects, project detail, materials/finishes, differentiators, testimonials and consultation/contact. The existing Interior concept image is reused through the shared media store. Repeated creation deduplicates identical normalized bytes. Placeholder copy explicitly asks for approved business content; sample testimonials are not presented as real customer endorsements.

Business/contact/logo bindings resolve from the reusable marketing kit at publication. Projects and materials are presentation cards, never direct public database queries. Template creation is gated by the plan's template capability; the generic document model and configurable brochure types also support Construction. No industry-specific table or duplicate business identity is introduced.

Template edits remain drafts until validated and published. Theme and component properties can be changed, pages duplicated/reordered and reusable blocks saved. Published editions remain frozen when a template definition or brand kit changes.
