# Playwright skip classification

The existing default suite has 117 test/project combinations. All 79 skips are listed below: **67 NOT APPLICABLE** to the selected application and **12 BLOCKED** by missing usable hosted staging/identities/configuration. No test was deleted, disabled or converted into a pass. Execution results are recorded separately in PHASE11-VERIFICATION.md.

NOT APPLICABLE refers only to a test on the wrong application (including component/PDF fixtures assigned to one composition root). The same test remains enabled on its intended application. For live tests, a wrong application is classified first even when the combined skip annotation also mentions credentials. Live Auth is applicable to both admin apps; other live tests belong to Business App.

BLOCKED cases require the explicit opt-in and disposable identities/configuration named by their annotations. Owner/dependency: unassigned staging/release operator and relevant Auth/signing/entitlement/provider configuration. Do not supply production credentials or change a skip merely to obtain a pass. The local recovery suite runs eight additional cases without hosted credentials; it is not a substitute for these live cases.

These twelve opt-in cases do not constitute the entire hosted acceptance matrix. Two-tenant RLS, all RBAC/entitlement revocations, private Storage, inbox recovery/email, worker/provider interruptions, backups and deployment rollback remain critical acceptance gaps in HOSTED-ACCEPTANCE.md and PROVIDER-RECOVERY.md. Missing infrastructure is BLOCKED, not NOT APPLICABLE.
