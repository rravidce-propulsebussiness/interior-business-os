# Snags: Phase 7

Snags follow open, assigned, in-progress, ready-for-review, verified and closed states, with reopening supported. Assignment checks active member/project access or an active organization vendor. Review requires resolution evidence; verification/closure/reopening require verification evidence. Each transition appends a project execution event.

Project forms support creation, assignment, rectification, review, verification, closure and reopening. The project document page exports the snag register. SQL tests cover lifecycle evidence, event history, tenant isolation and handover effects; competing closure commands are tested with separate database sessions.
