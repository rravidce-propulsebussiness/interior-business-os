# Brochure Builder

Open `/dashboard/brochures` with Brochure entitlement and `brochure.view`. Create a blank document or select one of seven editable templates. Each brochure has its own slug, type, draft revision, publication history and sharing settings. Duplication creates a new draft without copying enquiries or history. Archived brochures retain their editions.

The editor has page thumbnails, a component palette, a millimetre canvas and a properties panel. Add, copy, delete and reorder pages. Place components by dragging or exact X/Y/width/height/rotation fields; use margin/safe-area guides and optional 5 mm snapping. Layers support ordering, locking and hiding. Undo/redo retains 50 local editing operations. Save explicitly before print preview, export or publishing. Concurrent stale saves are rejected instead of overwriting another editor.

Components include headings, text, structured rich text, images, galleries, shapes, dividers, logos, CTAs, contact cards, services, projects, testimonials, team, statistics, pricing, tables, FAQs, timelines, process, maps, social links, page numbers, headers, footers, materials, finishes, room galleries, designers and consultation cards. Custom blocks are safe structured content, never executable HTML. Save a selected component into the organization block library. Image fit, focal point and position affect the layout without modifying original bytes. Media selection can load additional bounded pages of 25 assets.

Document settings control A4/A5 portrait or landscape, square or custom dimensions, margin, safe area, bleed, background, colors, fonts, page numbers and headers/footers. Component typography overrides are explicit. Brand tokens can be applied to the document; later brand changes do not modify published editions. Text does not automatically flow across pages: resize the box or add a page when print preflight identifies overflow.

The Brand & public content screen stores contact presentation, logos, approved public content, custom brochure types and reusable blocks. Business name comes from the existing organization. Import catalog/project titles only with the corresponding module permission, select safe presentation fields and explicitly approve them. A binding resolves at preview/export/publication; earlier editions retain their frozen content. Unapproved bound content blocks publication. Manual material/finish cards avoid exposing procurement prices, project notes or customer records.

The editor supports numeric resizing rather than corner resize handles. Rich text currently uses structured text and component-level typography, not a general HTML or inline-formatting editor. Group components are structured blocks; multi-selection group transformations are not implemented. See the verification report for remaining acceptance boundaries.
